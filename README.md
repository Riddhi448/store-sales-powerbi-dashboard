# store-sales-powerbi-dashboard

## 📊 Project Overview

This is a beginner-level Power BI practice project
created to analyze store sales data and visualize
business performance using interactive dashboards.

The dashboard was developed using an Excel dataset
and Power BI.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Power BI
- Data Visualization
- Data Analysis

## 📈 Key Metrics

- Total Sales
- Total Quantity Sold
- Total Profit
- Total Orders

## 📊 Dashboard Features

- Sales analysis by year and category
- Sales comparison across regions
- Sales analysis by sub-category
- State-wise sales visualization
- Interactive region filters
- KPI cards for business performance

## 🎯 Objective

The objective of this project was to practice
data visualization, dashboard design, and business
performance analysis using Power BI.
